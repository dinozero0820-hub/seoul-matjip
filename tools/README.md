# 서울 맛집 지도 — 데이터 업데이트 방법

이 사이트는 정적 파일만으로 돌아간다 (GitHub Pages).

| 파일 | 내용 |
|---|---|
| `index.html` | 지도 앱 (카카오맵) |
| `config.js` | 카카오 JavaScript 키, 선택: `GOATCOUNTER`(방문자 집계 코드), `REPORT_URL`(제보 폼), `RECOMMEND_URL`(추천 폼) |
| `pts.json` | 서울 영업 중 음식점 전체(좌표·분류)와 추천 집 정보·학교별 추천 목록 |
| `gu/0.json` … | 구별 가게 이름·주소 |
| `m.json`, `p.gz`, `n/*.gz` | 앱이 실제로 받는 압축 데이터 (`tools/build_app.py` 가 pts.json·gu 에서 자동 생성. 직접 고치지 않는다) |
| `u/…/index.html`, `sitemap.xml` | 학교별 검색용 페이지 (자동 생성) |
| `tools/campuses.json` | 학교 목록 (이름, slug, 중심 좌표) |
| `tools/curated.json` | 직접 조사한 추천 집 목록 |

## 추천 집 추가하기 (주간 작업)
1. `tools/campuses.json` 과 현재 `pts.json` 의 학교별 추천 수를 보고, 추천이 적은 학교부터 고른다.
2. 웹 검색으로 그 학교 근처 맛집 소개 글(매거진·리뷰 사이트)을 찾아 **사실만** 뽑는다: 가게 이름, 주소, 대표 메뉴와 가격, 맵기, 혼밥/늦게까지/단체/데이트/웨이팅. 한 줄 평은 내 말로 쓴다. 글·사진을 그대로 옮기지 않는다. 폐업 표시가 있는 집은 넣지 않는다.
3. `tools/curated.json` 끝에 항목을 추가한다 (형식은 `tools/add_curated.py` 맨 위 설명 참고).
4. `python3 tools/add_curated.py` 실행 → "반영 못 한 항목"을 확인하고, 주소 힌트를 고치거나 빼고 다시 돌린다. 엉뚱한 지점(다른 동네 체인점 등)에 붙으면 그 항목을 지운다.
5. (add_curated.py 가 끝에 학교 페이지와 앱용 압축 데이터를 자동으로 다시 만든다.) 커밋 후 `main` 에 푸시하면 1~2분 뒤 사이트에 반영된다.

## 가게 목록 전체 갱신 (폐업·신규)
서울시 일반음식점 인허가 정보 CSV(또는 공공데이터포털 API)가 필요하다. 이건 원본 CSV에서 다시 만드는 작업이라 별도 세션에서 한다.
